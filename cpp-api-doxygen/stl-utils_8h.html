Detailed Description

Small generic STL container utilities ported from kaldi/src/util/stl-utils.h.

It provides sortedness checks (IsSorted, IsSortedAndUniq), the sort-and-unique helper SortAndUniq, kaldi-format binary/text I/O for integer vectors (WriteIntegerVector, ReadIntegerVector), pointer vector helpers (DeletePointers, ContainsNullPointers), and hashing function objects for pairs and vectors (PairHasher, VectorHasher). These are used throughout the tree/event-map code.
