Detailed Description

Abstract interface for statistics that can be clustered.

This file is copied/modified from kaldi/src/itf/clusterable-itf.h.

It declares the abstract class Clusterable: a set of statistics (e.g. Gaussian sufficient statistics) that can be added, subtracted and scaled, and that reports an objective function \(\mathrm{Objf}\) and a normalizer (typically a count). Concrete implementations live in clusterable-classes.h (ScalarClusterable, GaussClusterable); the clustering algorithms that consume this interface live in cluster-utils.h. See kaldi's clustering documentation for an explanation of its function.
