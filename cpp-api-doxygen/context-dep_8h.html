Detailed Description

Decision-tree based implementation of context dependency.

This file is copied/modified from kaldi/src/tree/context-dep.h.

It declares ContextDependency, the concrete, decision-tree based implementation of ContextDependencyInterface (see context-dep-itf.h), and the factory functions MonophoneContextDependency and MonophoneContextDependencyShared that build trivial one-phone trees. The decision-tree nodes themselves are EventMap objects (event-map.h); this file only encodes the phone context as an event and queries the map. Training of the tree is deliberately kept out of this file (see build-tree-utils.h and cluster-utils.h for the tree-building side).
