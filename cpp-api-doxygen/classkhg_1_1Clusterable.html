Detailed Description

A virtual class for clusterable objects.

An instance represents sufficient statistics for one cluster. The operations Add, Sub and Scale update the statistics in place; Objf reports the objective function (to be maximized) of fitting the statistics with a single cluster, and ObjfPlus, ObjfMinus and Distance give the objective-function changes implied by merging or splitting clusters.
