DoubleVector khg::OnlineIvectorExtractor::GetIvector ( int32_t index) const

The iVector estimated after frame index * ivector_period frames.

Like kaldi's OnlineIvectorFeature output (and ivector-extract-online), PriorOffset() is removed from dimension 0 so the vector is roughly zero-mean; the raw estimate keeps the offset internally for CG warm starts.
