Detailed Description

GMM update flags and mixture-splitting targets.

This file is copied/modified from kaldi/src/gmm/model-common.h.

This module collects small shared pieces of the GMM training machinery:

  • GmmUpdateFlags / GmmFlagsType: bit flags selecting which GMM parameters (means, variances, weights, transitions) an accumulation or update works on, plus the string conversions StringToGmmFlags()/GmmFlagsToString() ("mvwt"/"a" style flag strings) and AugmentGmmFlags() for sanity-fixing flag combinations.
  • GetSplitTargets(): computes per-state numbers of mixture components (Gaussians or sub-states) for splitting, according to a power rule of the state occupancies.

See also kaldi/src/gmm/model-common.h.
