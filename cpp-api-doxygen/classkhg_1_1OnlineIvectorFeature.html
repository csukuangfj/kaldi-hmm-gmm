Detailed Description

kaldi's OnlineIvectorFeature (online2/online-ivector-feature.h).

The raw (base) features, e.g. MFCC, are pushed with AcceptFeatures() / InputFinished() instead of being pulled from an OnlineFeatureInterface. Two chains are built on top of them, exactly as in kaldi:

  • posteriors: online CMVN -> splice -> LDA -> UBM posteriors (top num_gselect Gaussians, pruned by min_post, scaled by posterior_scale and the frame weight);
  • stats: splice -> LDA (or the CMVN chain if online_cmvn_iextractor).

Stats are accumulated lazily, up to the frame asked for in GetFrame(). With use_most_recent_ivector (the default, and what vosk uses) GetFrame() returns the most recent estimate; otherwise the one of frame (frame / ivector_period) * ivector_period. Frame weights (silence weighting) are provided with UpdateFrameWeights(); once they are, every frame needs a weight before it is used (kaldi's semantics: frames get a weight of zero until a delta-weight for them arrives).

Not ported: the speaker adaptation state (SetAdaptationState / GetAdaptationState), the UBM log-likelihood diagnostics and the max_remembered_frames limit; every utterance starts from the global CMVN stats.

◆ UpdateFrameWeights()

void khg::OnlineIvectorFeature::UpdateFrameWeights ( const std::vector< std::pair< int32_t, float > > & delta_weights)

Provide frame weights as (frame, delta-weight) pairs (kaldi's UpdateFrameWeights).

The weights are deltas: a frame whose weight changes from w1 to w2 gets an entry with w2 - w1; frames already used in the stats are corrected the next time the stats are updated.
