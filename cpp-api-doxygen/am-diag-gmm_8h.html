Detailed Description

Acoustic model of diagonal-covariance GMMs (AmDiagGmm).

This file is copied/modified from ../kaldi/src/gmm/am-diag-gmm.h.

It provides khg::AmDiagGmm, the acoustic model used for GMM training: a collection of DiagGmm emission densities (see diag-gmm.h), one per pdf, indexed by pdf-id. The pdf-ids are the ids output by the Compute() function of the phonetic decision tree (ContextDependency) and returned by TransitionModel::TransitionIdToPdf(); they are zero-based and run from 0 to NumPdfs()-1, exactly as in kaldi (kaldi's ali-to-pdf writes zero-based pdf-ids). Note that FST- and decoder-facing interfaces sometimes number states from one for OpenFst compatibility; subtract one before calling the methods here.

The API falls into the following groups:

  • Construction: Init() fills the model with copies of one "prototype" GMM (one per pdf); AddPdf() appends a GMM one pdf at a time; the destructor frees the owned GMMs (copy construction and assignment are disabled).
  • Model manipulation: SplitPdf() splits the components of a single pdf; SplitByCount()/MergeByCount() grow/shrink all pdfs towards a total Gaussian target according to a power-of-occupancy rule; CopyFromAmDiagGmm() deep-copies another model; ComputeGconsts() refreshes the cached log-normalizers of all pdfs.
  • Scoring: LogLikelihood() evaluates one pdf on one frame.
  • Parameter access: GetPdf() returns a pdf (mutable or const), the Get/SetGaussian* methods address individual Gaussian components.
  • I/O: Read()/Write() use kaldi's on-disk format (the implementation is ported from ../kaldi/src/gmm/am-diag-gmm.cc and the file format is identical), so models are interchangeable with kaldi; a kaldi final.mdl stores this object together with a TransitionModel and a ContextDependency.

Typical usage: Init() the model from a prototype (e.g. a single-Gaussian model) with one pdf per tree leaf, score frames with LogLikelihood(), accumulate statistics with AccumAmDiagGmm (mle-am-diag-gmm.h), and re-estimate with MleAmDiagGmmUpdate().
