Detailed Description

Diagonal-covariance Gaussian mixture models (DiagGmm) stored in exponential form.

This file is copied/modified from ../kaldi/src/gmm/diag-gmm.h.

It provides khg::DiagGmm, the Gaussian mixture model with diagonal covariances that is used as the emission density of every pdf of the acoustic model (see am-diag-gmm.h). A model of \(M\) components in dimension \(D\) defines the density

\[ p(x) = \sum_{j=1}^{M} w_j \, \mathcal{N}(x; \mu_j, \mathrm{diag}(\sigma_j^2)), \]

where the mixture weights \(w_j\) are non-negative and should sum to one.

As in kaldi, the parameters are kept in exponential (natural) form: the linear weights \(w_j\), the inverse variances \(\sigma_j^{-2}\) and the means times inverse variances \(\mu_j \odot \sigma_j^{-2}\). This is the representation the statistics accumulators and the update formulas of mle-diag-gmm.h are written against. For each component a constant "gconst" \(g_j\) collecting the data-independent terms of the log-likelihood is cached (see ComputeGconsts()), so that per-component evaluation of

\[ \ell_j(x) = g_j + (\mu_j \odot \sigma_j^{-2})^{\top} x - \tfrac{1}{2} (\sigma_j^{-2})^{\top} (x \odot x) = \log w_j + \log \mathcal{N}(x; \mu_j, \mathrm{diag}(\sigma_j^2)) \]

is a single inner product per component, and the full log-likelihood is

\[ \log p(x) = \log \sum_j w_j \, \mathcal{N}(x; \mu_j, \mathrm{diag}(\sigma_j^2)) = \mathrm{logsumexp}_j \, \ell_j(x). \]

The API falls into the following groups:

  • Construction and sizing: the default, copy and sizing constructors, the constructor from explicit parameters, the merge constructor from several weighted GMMs, Resize() and CopyFromDiagGmm().
  • Parameter access and mutation: weights(), means_invvars(), inv_vars(), gconsts() and valid_gconsts(); SetWeights()/SetMeans()/SetInvVars()/ SetInvVarsAndMeans() for whole matrices, the per-component setters and getters (SetComponentWeight(), SetComponentMean(), SetComponentInvVar(), GetComponentMean(), GetComponentVariance()), and GetMeans()/GetVars() which expose the parameters in normal (mean/variance) form.
  • Likelihood evaluation: LogLikelihood(), LogLikelihoods(), LogLikelihoodsMatrix(), LogLikelihoodsPreselect(), ComponentPosteriors() and ComponentLogLikelihood().
  • Gaussian selection for pruning: GaussianSelection() (single frame and matrix versions) and GaussianSelectionPreselect().
  • Model manipulation: Split()/Merge()/MergeKmeans() change the number of components; RemoveComponent()/RemoveComponents() drop components; Interpolate() and Perturb() modify the parameters; Generate() samples a feature vector from the model.
  • I/O: Read()/Write() use kaldi's on-disk format (the implementation is ported from ../kaldi/src/gmm/diag-gmm.cc and the file format is identical), so models are interchangeable with kaldi.

Usage notes:

  • The weights must be positive (checked by the merge constructor) and should sum to one for \(p\) to be a properly normalized density; the variances must be positive. ComputeGconsts() treats zero weights or variances as "invalid" components and counts them.
  • ComputeGconsts() must be called after any parameter change and before likelihood evaluation or Write(). Every mutator marks the cached gconsts as stale (valid_gconsts() returns false) until the next ComputeGconsts().
  • If you need plain means and variances (e.g. for the MLE/MAP update formulas or for smoothing), use DiagGmmNormal from diag-gmm-normal.h, a friend class that converts to and from this exponential form.
