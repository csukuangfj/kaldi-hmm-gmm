Detailed Description

Definition for Gaussian Mixture Model with diagonal covariances.

Stores \(M\) diagonal-covariance Gaussian components in exponential form: weights_ holds the linear mixture weights \(w_j\), inv_vars_ holds the inverse variances \(\sigma_j^{-2}\) (one row per component), and means_invvars_ holds the means times inverse variances \(\mu_j \odot \sigma_j^{-2}\). The cached per-component gconsts are

\[ g_j = \log w_j - \frac{1}{2} \Big( D \log 2\pi + \sum_{d} \log \sigma_{jd}^{2} + \sum_{d} \frac{\mu_{jd}^{2}}{\sigma_{jd}^{2}} \Big) = \log w_j + \log \mathcal{N}(0; \mu_j, \mathrm{diag}(\sigma_j^2)), \]

so that \(\ell_j(x) = g_j + (\mu_j \odot \sigma_j^{-2})^{\top} x - \tfrac{1}{2} (\sigma_j^{-2})^{\top} (x \odot x)\).
