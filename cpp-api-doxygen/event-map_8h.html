Detailed Description

Generic mapping from integer events to integer answers (decision trees).

This file is copied/modified from kaldi/src/tree/event-map.h.

An EventMap represents a mapping from an EventType – a sorted vector of (key, value) integer pairs, i.e. one "event" – to an integer answer (EventAnswerType), e.g. a pdf-id. It is the data structure underlying Kaldi's decision trees: the leaves hold answers and the internal nodes (SplitEventMap, TableEventMap) ask questions about individual event keys. See kaldi's tree_internals documentation for an overview.

The file provides:

  • The event types: EventKeyType, EventValueType, EventAnswerType, EventType, and small helpers (MakeEventPair, WriteEventType, ReadEventType, EventTypeToString).
  • The abstract base class EventMap and its three node kinds: ConstantEventMap (leaf), TableEventMap (multi-way split on a key), SplitEventMap (binary yes/no split on a key).
  • GetTreeStructure, which extracts the tree topology of an EventMap.

Building trees from statistics is done in build-tree-utils.h / cluster-utils.h; using them for context dependency is done in context-dep.h.
