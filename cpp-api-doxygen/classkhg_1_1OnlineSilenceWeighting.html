Detailed Description

kaldi's OnlineSilenceWeighting: turns the decoder's best-path traceback into per-frame weights for OnlineIvectorFeature::UpdateFrameWeights(), down-weighting silence frames.

Differences from kaldi: ComputeCurrentTraceback() takes the best path as transition-ids (one per decoder frame) instead of the decoder object, so this library stays independent of the decoder; get them from kaldi-decoder's GetBestPathTransitionIds() (LatticeFasterOnlineDecoder). The resulting weights are the same.
