Detailed Description

GaussClusterable wraps Gaussian statistics in a form accessible to generic clustering algorithms.

It accumulates, per dimension \(d\), the count \(n\), the sum \(x_d\) and the sum of squares \(x^{(2)}_d\). Writing \(\mu_d = x_d / n\) and \(\sigma_d^2 = x^{(2)}_d / n - \mu_d^2\) with the floored variance \(\tilde{\sigma}_d^2 = \max(\sigma_d^2, \sigma_{\mathrm{floor}})\), the objective function (to be maximized) is the (variance-floored) Gaussian log-likelihood of the accumulated stats,

\[ \mathrm{Objf} = n \left[ \sum_{d} \left( -\frac{1}{2} \frac{\sigma_d^2}{\tilde{\sigma}_d^2} -\frac{1}{2} \log \tilde{\sigma}_d^2 \right) - \frac{D}{2} \log(2\pi) \right], \]

where \(D\) is the dimension; it is zero when \(n \le 0\).
