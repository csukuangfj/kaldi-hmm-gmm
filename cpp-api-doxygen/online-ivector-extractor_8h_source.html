31// Streaming i-vector extractor reproducing the dataflow of kaldi's
32// OnlineIvectorFeature (online2/online-ivector-feature.cc):
33//
34// posteriors: running-CMVN -> splice(+-L,R) -> lda -> UBM (DiagGmm)
35// stats: [running-CMVN ->] splice(+-L,R) -> lda (raw by default,
36// i.e. online_cmvn_iextractor=false like vosk's models)
37// then IvectorEstimationStats accumulation, iVector re-estimated every
38// ivector_period frames (warm-started CG, max_count prior scaling).
39
