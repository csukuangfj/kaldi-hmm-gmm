Detailed Description

Statistics accumulator for a whole AmDiagGmm.

Wraps one AccumDiagGmm per pdf (indexed by pdf-id) and keeps running totals of the accumulated frame count and log-likelihood for diagnostics. The accumulator list is sized by Init() and the object owns its accumulators (copy construction and assignment are disabled).
