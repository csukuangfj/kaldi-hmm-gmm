Detailed Description

ScalarClusterable clusters scalars with x^2 loss.

It accumulates the count \(n\), the sum \(x\) and the sum of squares \(x_2\) of a set of scalars. The objective function (to be maximized) is the negated weighted sum of squared distances to the mean, \(\mathrm{Objf} = -(x_2 - x^2 / n)\) (zero when \(n = 0\)).
