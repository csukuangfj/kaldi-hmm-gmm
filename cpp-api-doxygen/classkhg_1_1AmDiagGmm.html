Detailed Description

Acoustic model: a collection of diagonal-covariance GMMs, one per pdf, indexed by pdf-id.

Each pdf is a DiagGmm owned by this object; the pdf-ids are zero-based indices into the internal list (see the file docs). The model owns its GMMs and frees them in the destructor; copying is disabled.

◆ MergeByCount()

void khg::AmDiagGmm::MergeByCount ( const FloatVector & state_occs,
int32_t target_components,
float power,
float min_count )

In MergeByCount we use the "target_components" and "power" to work out targets for each state (according to power-of-occupancy rule), and any state over its target gets mixed down.

If some states were under their target, this may take the Gauss below the target.

Parameters
state_occs1-D float tensor of shape (num_pdfs,)
target_componentsExpected sum of number of gaussians in all pdfs
powerIt is used to compute state_occs.pow(power)
min_countThe per-pdf target is capped so that each Gaussian retains at least this average occupancy (a LARGER value forces MORE merging, never less).

◆ SplitByCount()

void khg::AmDiagGmm::SplitByCount ( const FloatVector & state_occs,
int32_t target_components,
float perturb_factor,
float power,
float min_count )

In SplitByCount we use the "target_components" and "power" to work out targets for each state (according to power-of-occupancy rule), and any state less than its target gets mixed up.

If some states were over their target, this may take the Gauss over the target. we enforce a min-count on Gaussians while splitting (don't split if it would take it below min-count).

Parameters
state_occsA 1-D float tensor of shape (num_pdfs,)
target_componentsExpected sum of number of gaussian in all pdfs
perturb_factorto use when splitting a GMM
powerIt is used to compute state_occs.pow(power)
min_countIf the average of occupancy of gaussians in a pdf is less than this number, then we won't split this pdf any more
