Detailed Description

Immutable integer set with fast membership tests.

This file is copied and modified from kaldi/src/util/const-integer-set.h.

It declares ConstIntegerSet, a read-only set of integers that is initialized once (from a vector or set) and then supports efficient membership queries (count) and iteration. Depending on the density of the input it stores either a sorted vector (binary search) or a bit/bool lookup table, giving O(1) membership in the dense case. It is used e.g. by SplitEventMap in event-map.h to test question membership quickly; the member function bodies live in const-integer-set-inl.h.
