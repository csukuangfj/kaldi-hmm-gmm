Detailed Description

Eigen typedefs matching kaldi's Matrix layout, plus small vector math and random helpers.

This file defines the fixed-layout matrix/vector typedefs used throughout the library: dynamic-size matrices are row-major (like kaldi's Matrix<double>/Matrix<float>) and vectors are column vectors. It also provides a few small utilities: LogSumExp and Softmax over FloatVector, and normally distributed random number generators (Randn, RandnVector, RandnMatrix) analogous to the helpers in kaldi/src/base/kaldi-math.h.
