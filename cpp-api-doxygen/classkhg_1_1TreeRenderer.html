Detailed Description

Parses a decision tree file and outputs its description in GraphViz format.

The renderer walks the EventMap nodes (see event-map.h) and emits one GraphViz node per tree node: leaf (ConstantEventMap) nodes as boxes, and non-leaf (SplitEventMap, TableEventMap) nodes as ellipses labeled with the question asked (a phone from the context window or the pdf-class). An optional query event can be rendered as a distinctly colored trace through the tree.
