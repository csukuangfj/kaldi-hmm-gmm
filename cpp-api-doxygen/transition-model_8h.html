Detailed Description

Transition probabilities and integer-id mappings for HMM-GMM models.

This file is copied/modified from kaldi/src/hmm/transition-model.h.

The main class, TransitionModel, is the repository for the HMM transition probabilities of an acoustic model and the place where the toolkit's integer id spaces (phone, HMM-state, pdf-id, transition-state, transition-index, transition-id) are defined and mapped onto each other. The transition probabilities are associated with (phone, HMM-state, pdf-id) triples that are resolved through the phonetic decision tree; the pdf-classes of the HMM topology are replaced by actual pdf-ids via the ContextDependencyInterface.

The API falls into the following groups:

  • Construction and I/O: initialization from a ContextDependencyInterface and a HmmTopology (e.g. at the start of training), and kaldi-compatible Read()/Write() (no symbol table; the topology is always stored without symbols).
  • Integer mappings between the id spaces (see the TransitionModel class docs): TupleToTransitionState(), PairToTransitionId(), TransitionIdToTransitionState(), TransitionStateToPhone(), TransitionStateToHmmState(), TransitionStateToForwardPdf(), TransitionStateToSelfLoopPdf(), ...
  • Transition probabilities: GetTransitionProb(), GetTransitionLogProb(), GetTransitionLogProbIgnoringSelfLoops(), GetNonSelfLoopLogProb(), SelfLoopOf(). Transition costs used inside graphs are \(-\log p\), possibly scaled.
  • Training: InitStats()/Accumulate() gather counts indexed by transition-id; MleUpdate() performs maximum-likelihood re-estimation of the transition probabilities (configured by MleTransitionUpdateConfig).

TransitionModel implements the kaldi_decoder::TransitionInformation interface from the kaldi-decoder project; that is how the decoder stack learns the transition-id-to-pdf mapping and per-transition-id properties without depending on this class directly.

Typical usage: construct the object from the same tree and topology that were used to build the model; persist it in a kaldi-style final.mdl together with an AmDiagGmm and a ContextDependency; use it to map alignments (transition-id sequences) to pdfs and phones, and to look up transition probabilities during graph construction and decoding.

See also kaldi/src/hmm/transition-model.h.
