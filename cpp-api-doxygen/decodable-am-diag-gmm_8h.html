Detailed Description

Decodable objects for AmDiagGmm acoustic models.

This file is copied/modified from kaldi/src/gmm/decodable-am-diag-gmm.h.

This module provides the decodable objects used to score frames with a diagonal-covariance GMM acoustic model (AmDiagGmm); they implement the kaldi_decoder::DecodableInterface from the kaldi-decoder project and are what kaldi's gmm-align-compiled and decoding binaries plug into the alignment/decoding machinery:

  • DecodableAmDiagGmmUnmapped: indices are pdf-ids plus one, so no transition model is involved.
  • DecodableAmDiagGmmScaled: indices are transition-ids (one-based); the GMM log-likelihood of the transition-id's pdf is returned multiplied by an acoustic scale, so acoustic scores can be weighted relative to the graph (transition and language model) scores.

Usage notes: frames are numbered from zero while indices are one-based (for compatibility with OpenFst). The decodables cache per-pdf likelihoods and support optional pruning of the LogSumExp over mixture components. Transition probabilities are not part of these scores; they live on the graph arcs (see hmm-utils.h).

See also kaldi/src/gmm/decodable-am-diag-gmm.h.
