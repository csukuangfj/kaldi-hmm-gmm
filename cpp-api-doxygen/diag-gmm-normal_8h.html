Detailed Description

Normal (mean/variance) representation of diagonal GMMs (DiagGmmNormal).

This file is copied/modified from kaldi/src/gmm/diag-gmm-normal.h.

It provides khg::DiagGmmNormal, a lightweight companion of DiagGmm (diag-gmm.h) that stores the parameters of a diagonal-covariance GMM in plain "normal" form: linear mixture weights, means and diagonal variances, all in double precision. This is the form the MLE/MAP update formulas of mle-diag-gmm.h are written in, and the form used for smoothing and for serializing parameters outside the kaldi on-disk format.

The API is deliberately minimal:

  • CopyFromDiagGmm() converts a DiagGmm from its exponential form ( \(\mu \odot \sigma^{-2}\), \(\sigma^{-2}\)) to plain means and variances; the constructor from a DiagGmm does the same.
  • CopyToDiagGmm() converts back, optionally copying only the parameter groups selected by GmmUpdateFlags (weights, means, variances).
  • NumGauss()/Dim() report the size; the parameters are exposed as the public members weights_, means_ and vars_ so that updates can modify them in place.

Typical usage: construct from the DiagGmm being updated, modify the public members with the estimation formulas, then CopyToDiagGmm() with the desired flags and call DiagGmm::ComputeGconsts().
