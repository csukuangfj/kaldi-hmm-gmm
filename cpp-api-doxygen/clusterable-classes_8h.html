Detailed Description

Concrete Clusterable classes holding scalar and Gaussian statistics.

This file is copied/modified from kaldi/src/tree/clusterable-classes.h.

It provides two concrete implementations of the Clusterable interface (clusterable-itf.h):

  • ScalarClusterable, which clusters scalars with an \(x^2\) loss.
  • GaussClusterable, which wraps per-dimension Gaussian sufficient statistics (sum and sum-of-squares) in a form accessible to generic clustering algorithms.

The Gaussian statistics are stored as DoubleVector (see eigen.h), which corresponds to kaldi's Matrix<double> layout of two rows (sum, then sum-squared) here split into two separate vectors.
