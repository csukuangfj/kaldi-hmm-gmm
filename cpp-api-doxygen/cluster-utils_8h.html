Detailed Description

K-means-like clustering of Clusterable statistics.

This file is copied/modified from kaldi/src/tree/cluster-utils.h.

It provides ClusterKMeans, a k-means-like clustering algorithm over generic Clusterable objects (clusterable-itf.h, clusterable-classes.h), its configuration types RefineClustersOptions and ClusterKMeansOptions, and summary helpers (SumClusterableObjf, SumClusterableNormalizer, SumClusterable). These are used by the decision-tree building code (build-tree-utils.h) to cluster sets of statistics. The objective functions involved are the Clusterable::Objf() values; clustering always tries to maximize their sum.
