Detailed Description

Logging and assertion macros used throughout the library.

This file is copied/modified from kaldi/src/base/kaldi-error.h.

It provides the Logger stream-style logging class and the macros KHG_LOG (info), KHG_WARN (warning) and KHG_ERR (error; throws std::runtime_error when the message is flushed), the assertion macros KHG_ASSERT and KHG_PARANOID_ASSERT (the latter active only when KHG_PARANOID is defined), and the convenience macro KHG_DISALLOW_COPY_AND_ASSIGN. Usage is like kaldi's KALDI_LOG / KALDI_WARN / KALDI_ERR, e.g. KHG_ASSERT(x); KHG_ERR << "bad value: " << v;.
