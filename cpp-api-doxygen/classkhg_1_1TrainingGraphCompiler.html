Detailed Description

Compiles per-utterance training graphs labeled with transition-ids.

A TrainingGraphCompiler assembles HCLG-style graphs for training: the lexicon fst (L) is composed with the utterance's grammar/acceptor (G), the result is expanded to phone context (C) via the InverseContextFst, the H transducer is built by GetHTransducer() and composed in, the result is determinized and minimized, and finally AddSelfLoops() adds the self-loops. The transition/self-loop probabilities are baked in at the scales configured in TrainingGraphCompilerOptions (the compile-train-graphs convention is to use scales 0 and apply AddTransitionProbs() at alignment time; see the file documentation).

The compiler keeps (and modifies) the lexicon fst it was given and caches matcher state between compilations, so compiling many graphs at once is faster than compiling them one at a time.

fst::VectorFst< fst::StdArc > * out_fst )

CompileGraph compiles a single training graph its input is a weighted acceptor (G) at the word level, its output is HCLG.

Note: G could actually be a transducer, it would also work. This function is not const for technical reasons involving the cache. if not for "table_compose" we could make it const.

Parameters
word_grammar[in] The utterance's grammar at the word level.
out_fst[out] The compiled training graph (transition-id to word transducer).
Returns
True on success; false if the graph could not be compiled.
