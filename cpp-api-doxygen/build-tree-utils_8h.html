Detailed Description

Helpers for building decision trees from statistics.

This file is copied/modified from kaldi/src/tree/build-tree-utils.h.

It provides the tree-building helper GetStubMap, which creates the initial to-states (to-pdf) map that seeds the decision-tree-building process: a trivial EventMap that splits only on groups of phones and on HMM position. Kaldi's build-tree-utils.h contains many more helpers for building and refining trees from statistics (see also cluster-utils.h).
