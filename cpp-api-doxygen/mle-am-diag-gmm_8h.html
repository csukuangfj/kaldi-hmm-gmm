Detailed Description

ML/MAP estimation for whole acoustic models of diagonal GMMs.

This file is copied/modified from ../kaldi/src/gmm/mle-am-diag-gmm.h.

It provides the model-level counterparts of the per-GMM estimation code in mle-diag-gmm.h:

  • AccumAmDiagGmm: one AccumDiagGmm per pdf of an AmDiagGmm, plus running totals of the frame count and log-likelihood for diagnostics.
  • MleAmDiagGmmUpdate() and MapAmDiagGmmUpdate(): apply MleDiagGmmUpdate()/MapDiagGmmUpdate() to every pdf and report the summed objective change and count.

The update functions take the same MleDiagGmmOptions / MapDiagGmmOptions and the same GMM update flags as their per-GMM counterparts (see the "GMM update flags" section in mle-diag-gmm.h); there is no separate options struct at the acoustic-model level. The reported objective change is the sum of the per-pdf changes of the ML objective (MlObjective()), so it can be printed as the usual GMM update: objf impr (...) line of kaldi's gmm-est.

Typical usage (mirrors kaldi's gmm-acc-stats-ali + gmm-est): create an AccumAmDiagGmm, Init() it from the model, fill it with AccumulateForGmm() once per frame of the training data, then call MleAmDiagGmmUpdate() and AmDiagGmm::ComputeGconsts().
