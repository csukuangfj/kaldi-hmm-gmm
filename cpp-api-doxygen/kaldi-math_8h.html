Detailed Description

Small math helpers ported from kaldi/src/base/kaldi-math.h.

This file is copied/modified from kaldi/src/base/kaldi-math.h.

It provides the constants kMinLogDiffDouble / kMinLogDiffFloat and kPi, the log-domain addition helpers LogAdd and Log1p, the comparison helper ApproxEqual, and simple random number generation (RandomState, Rand, RandUniform) plus Gcd.
