Detailed Description

Definition for Gaussian Mixture Model with diagonal covariances in normal mode: where the parameters are stored as means and variances (instead of the exponential form that the DiagGmm class is stored as).

This class will be used in the update (since the update formulas are for the standard class. The DiagGmmNormal class will not be used anywhere else, and should not have any extra methods that are not needed.

void khg::DiagGmmNormal::CopyToDiagGmm ( DiagGmm * diaggmm,
GmmFlagsType flags = kGmmAll ) const

Copies to DiagGmm the requested parameters Only the parameter groups selected by flags are transferred (weights for kGmmWeights, variances for kGmmVariances, means for kGmmMeans).

If the variances are copied without the means, the means-times-inverse-variances of the target are recomputed from its old means and the new variances. The target's gconsts are invalidated.

Parameters
diaggmmThe model to convert to; must have the same number of components and dimension as this object.
flagsWhich parameter groups to copy (default: all).
