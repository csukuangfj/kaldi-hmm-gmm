Detailed Description

Renders a decision tree (EventMap) in GraphViz (dot) format.

This file is copied/modified from kaldi/src/tree/tree-renderer.h.

It declares TreeRenderer, which reads a decision tree (a ContextDependency to-pdf EventMap) from a stream and writes its description in GraphViz format, with phone-symbol edge labels taken from an fst::SymbolTable. It is used to visualize context-dependency trees, e.g. by the Python draw_tree helper.
