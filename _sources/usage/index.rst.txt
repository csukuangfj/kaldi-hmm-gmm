Usage
=====

Start with :doc:`setup` — it installs everything the examples need (no C++
build required).  Then run the complete, copy-paste runnable tutorials:

Colab notebooks (runnable in the browser):

* |mfa english colab| — MFA forced alignment, English
* |mfa chinese colab| — MFA forced alignment, Chinese
