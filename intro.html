Introduction

kaldi-hmm-gmm provides the acoustic-modeling side of kaldi's GMM pipeline as a library: you can train monophone GMM systems, compile training graphs, force align audio to a known transcript, and decode with HCLG graphs — all from C++ or Python, with no kaldi binaries involved.

It is written in C++ (Eigen for the numerics) and comes with pybind11 Python bindings (package kaldi_hmm_gmm). The decoding engine (lattice decoders, decoder wrappers, lattice best path) lives in the sibling project kaldi-decoder; kaldi-hmm-gmm links its C++ core and implements its DecodableInterface / TransitionInformation.

How the pieces map to kaldi

Each header is copied/modified from the corresponding kaldi source (the file header names it). File and function names deliberately follow kaldi so you can cross-reference kaldi/src directly:

kaldi-hmm-gmm

kaldi

TransitionModel

src/hmm/transition-model.h

HmmTopology

src/hmm/hmm-topology.h

GetHTransducer

src/hmm/hmm-utils.h

TrainingGraphCompiler

src/decoder/training-graph-compiler.h

DecodableAmDiagGmmScaled

src/gmm/decodable-am-diag-gmm.h

MleDiagGmmUpdate

src/gmm/mle-diag-gmm.h

Two end-to-end examples are documented in Usage: the kaldi yesno recipe (train a monophone GMM from scratch) and MFA-style forced alignment with pretrained acoustic models.
