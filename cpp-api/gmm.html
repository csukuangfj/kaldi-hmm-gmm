API (doxygen)

class DiagGmm

Definition for Gaussian Mixture Model with diagonal covariances.

Stores \(M\) diagonal-covariance Gaussian components in exponential form: weights_ holds the linear mixture weights \(w_j\), inv_vars_ holds the inverse variances \(\sigma_j^{-2}\) (one row per component), and means_invvars_ holds the means times inverse variances \(\mu_j \odot \sigma_j^{-2}\). The cached per-component gconsts are

\[ g_j = \log w_j - \frac{1}{2} \Big( D \log 2\pi + \sum_{d} \log \sigma_{jd}^{2} + \sum_{d} \frac{\mu_{jd}^{2}}{\sigma_{jd}^{2}} \Big) = \log w_j + \log \mathcal{N}(0; \mu_j, \mathrm{diag}(\sigma_j^2)), \]
so that \(\ell_j(x) = g_j + (\mu_j \odot \sigma_j^{-2})^{\top} x - \tfrac{1}{2} (\sigma_j^{-2})^{\top} (x \odot x)\).

class AmDiagGmm

Each pdf is a DiagGmm owned by this object; the pdf-ids are zero-based indices into the internal list (see the file docs). The model owns its GMMs and frees them in the destructor; copying is disabled.

void SplitByCount(const FloatVector &state_occs, int32_t target_components, float perturb_factor, float power, float min_count)

In SplitByCount we use the "target_components" and "power" to work out targets for each state (according to power-of-occupancy rule), and any state less than its target gets mixed up.

If some states were over their target, this may take the Gauss over the target. we enforce a min-count on Gaussians while splitting (don't split if it would take it below min-count).

Parameters:

  • state_occs -- A 1-D float tensor of shape (num_pdfs,)

  • target_components -- Expected sum of number of gaussian in all pdfs

  • perturb_factor -- to use when splitting a GMM

  • power -- It is used to compute state_occs.pow(power)

  • min_count -- If the average of occupancy of gaussians in a pdf is less than this number, then we won't split this pdf any more

void MergeByCount(const FloatVector &state_occs, int32_t target_components, float power, float min_count)

In MergeByCount we use the "target_components" and "power" to work out targets for each state (according to power-of-occupancy rule), and any state over its target gets mixed down.

Parameters:

  • min_count -- The per-pdf target is capped so that each Gaussian retains at least this average occupancy (a LARGER value forces MORE merging, never less).

DoubleVector variance_floor_vector

Variance floor for each dimension [empty if not supplied].

It is in double since the variance is computed in double precision. When non-empty it takes precedence over min_variance. There is no kaldi command-line flag for it; it is set programmatically (kaldi only registers the four options below).

float min_gaussian_weight

Minimum weight below which a Gaussian is not updated (and is removed, if remove_low_count_gaussians == true); kaldi flag --min-gaussian-weight; default 1.0e-05.

float min_gaussian_occupancy

Minimum count below which a Gaussian is not updated (and is removed, if remove_low_count_gaussians == true).

kaldi flag --min-gaussian-occupancy; default 10.0.

double min_variance

Minimum allowed variance in any dimension (if no variance floor) It is in double since the variance is computed in double precision.

kaldi flag --min-variance; default 0.001.

bool remove_low_count_gaussians

If true, remove Gaussians whose occupancy or weight falls below the floors above (the last remaining Gaussian is never removed).

kaldi flag --remove-low-count-gaussians; default true.

class AccumDiagGmm

Statistics accumulator for one DiagGmm.

Holds the zero-order (occupancy), first-order (mean) and second-order (variance) accumulators for each mixture component, in double precision. The accumulators that are actually stored are controlled by the flags given at construction: occupancy is stored for kGmmWeights, the mean accumulator for kGmmMeans, and the variance accumulator for kGmmVariances (which implies kGmmMeans; see AugmentGmmFlags()).
