API (doxygen)

class DecodableAmDiagGmmScaled : public khg::DecodableAmDiagGmmUnmapped

Decodable for an AmDiagGmm whose indices are transition-ids, with acoustic scaling.

This is the decodable used by kaldi's alignment and decoding tools (e.g. gmm-align-compiled). It maps the transition-id to its pdf via the TransitionModel (the self-loop pdf for self-loops, the forward pdf otherwise) and returns the GMM log-likelihood of that pdf, multiplied by the acoustic scale \(s\):

\[ \mathrm{LogLikelihood}(t, \mathrm{tid}) \;=\; s \cdot \log p\!\left(\mathbf{x}_t \mid \mathrm{pdf}(\mathrm{tid})\right). \]
The acoustic scale weights the acoustic log-likelihoods relative to the graph scores (transition and language-model probabilities live on the graph arcs and are not included in these scores). Frames are numbered from zero but transition-ids from one.

class DecodableAmDiagGmmUnmapped : public kaldi_decoder::DecodableInterface

DecodableAmDiagGmmUnmapped is a decodable object that takes indices that correspond to pdf-id's plus one.

This may be used in future in a decoder that doesn't need to output alignments, if we create FSTs that have the pdf-ids plus one as the input labels (we couldn't use the pdf-ids themselves because they start from zero, and the graph might have epsilon transitions).

Subclassed by khg::DecodableAmDiagGmmScaled

Public Functions

If you set log_sum_exp_prune to a value greater than 0 it will prune in the LogSumExp operation (larger = more exact); I suggest 5. This is advisable if it's spending a long time doing exp operations.
