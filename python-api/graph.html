class kaldi_hmm_gmm.Clusterable
class kaldi_hmm_gmm.ScalarClusterable(*args, **kwargs)

Maximize the negated sum of squared distances from the cluster center to each scalar.

Suppose there are n scalars \(x_1\), \(x_2\), ..., \(x_n\), the cluster center is defined as:

\[x = \frac{x_1 + x_2 + ... + x_n}{n}\]

The objective function is:

\[\begin{split}-1 *\left( (x_1 - x)^2 + (x_2 - x)^2 + ... + (x_n - x)^2 \right) &= -1 *\left( \sum_i^n(x_i - x)^2 \right) \\ &= -1 * \left( \sum_{i=1}^n (x_i - \frac{\sum_{k=1}^n x_k}{n})^2 \right)\\ & = -1 * \left( \sum_{i=1}^n (x_i^2 + \frac{\left( \sum_{k=1}^n x_k \right)^2}{n^2} - 2 x_i \frac{\sum_{k=1}^n x_k}{n} \right)\\ &= -1 * \left( \sum_{i=1}^n x_i^2+ n \frac{\left( \sum_{k=1}^n x_k \right)^2}{n^2} - 2 \sum_{i=1}^n x_i \frac{\sum_{k=1}^n x_k}{n} \right)\\ &= -1 * \left( \sum_{i=1}^n x_i^2+ n \frac{\left( \sum_{k=1}^n x_k \right)^2}{n^2} - 2\left( \sum_{i=1}^n x_i \right)\frac{\sum_{k=1}^n x_k}{n} \right) \\ &= -1 * \left( \sum_{i=1}^n x_i^2 + \frac{\left( \sum_{k=1}^n x_k \right)^2}{n} - 2 \frac{\left( \sum_{k=1}^n x_k \right)^2}{n} \right)\\ &= -1 * \left( \sum_{i=1}^n x_i^2 - \frac{\left( \sum_{k=1}^n x_k \right)^2}{n} \right)\\\end{split}\]

The goal is to maximize the objective function.

Its objf is defined as:

return -(x2_ - x_ * x_ / count_);

where x2 is the second order statistics, x_ is the first order statistics, and count_ is the number of scalars.

When adding two ScalarClusterable, we use:

x_ += other->x_;
x2_ += other->x2_;
count_ += other->count_;

When subtracting one ScalarClusterable from another, we use:

x_ -= other->x_;
x2_ -= other->x2_;
count_ -= other->count_;
