class kaldi_hmm_gmm.DecodableInterface(self: kaldi_hmm_gmm.lib._kaldi_hmm_gmm.DecodableInterface)

Scoring interface every decoder consumes.

This is kaldi's DecodableInterface. It answers one question: how likely is transition-id ``index`` at frame ``frame``? Implement it in Python to plug any acoustic model into kaldi_hmm_gmm's alignment/decoding functions (a pybind11 trampoline keeps virtual dispatch on the Python side).

Indices are one-based (openfst convention, 0 is epsilon).

Lifetime: decoders borrow the decodable without owning it -- keep the Python object alive for the whole decode.

See also

DecodableAmDiagGmmScaled The GMM-backed implementation for kaldi-format acoustic models.

Construct a decodable; implement the four methods below.

is_last_frame(self: kaldi_hmm_gmm.lib._kaldi_hmm_gmm.DecodableInterface, frame: SupportsInt) → bool

Whether frame is the last frame with scores available.

For streaming decodables this is only true once the input is finished.

log_likelihood(self: kaldi_hmm_gmm.lib._kaldi_hmm_gmm.DecodableInterface, frame: SupportsInt, index: SupportsInt) → float

Acoustic log-likelihood of transition-id index at frame frame (higher is better).

Parameters:

  • frame -- Frame index, 0-based, frame < num_frames_ready().

  • index -- Transition-id, 1-based, index <= num_indices().

Returns:

The log-likelihood.

num_frames_ready(self: kaldi_hmm_gmm.lib._kaldi_hmm_gmm.DecodableInterface) → int

Number of frames with scores available; may grow over time.

num_indices(self: kaldi_hmm_gmm.lib._kaldi_hmm_gmm.DecodableInterface) → int

Number of valid indices (transition-ids); indices are 1-based.

class kaldi_hmm_gmm.ScalarClusterable(*args, **kwargs)

Maximize the negated sum of squared distances from the cluster center to each scalar.

Suppose there are n scalars \(x_1\), \(x_2\), ..., \(x_n\), the cluster center is defined as:

\[x = \frac{x_1 + x_2 + ... + x_n}{n}\]

The objective function is:

\[\begin{split}-1 *\left( (x_1 - x)^2 + (x_2 - x)^2 + ... + (x_n - x)^2 \right) &= -1 *\left( \sum_i^n(x_i - x)^2 \right) \\ &= -1 * \left( \sum_{i=1}^n (x_i - \frac{\sum_{k=1}^n x_k}{n})^2 \right)\\ & = -1 * \left( \sum_{i=1}^n (x_i^2 + \frac{\left( \sum_{k=1}^n x_k \right)^2}{n^2} - 2 x_i \frac{\sum_{k=1}^n x_k}{n} \right)\\ &= -1 * \left( \sum_{i=1}^n x_i^2+ n \frac{\left( \sum_{k=1}^n x_k \right)^2}{n^2} - 2 \sum_{i=1}^n x_i \frac{\sum_{k=1}^n x_k}{n} \right)\\ &= -1 * \left( \sum_{i=1}^n x_i^2+ n \frac{\left( \sum_{k=1}^n x_k \right)^2}{n^2} - 2\left( \sum_{i=1}^n x_i \right)\frac{\sum_{k=1}^n x_k}{n} \right) \\ &= -1 * \left( \sum_{i=1}^n x_i^2 + \frac{\left( \sum_{k=1}^n x_k \right)^2}{n} - 2 \frac{\left( \sum_{k=1}^n x_k \right)^2}{n} \right)\\ &= -1 * \left( \sum_{i=1}^n x_i^2 - \frac{\left( \sum_{k=1}^n x_k \right)^2}{n} \right)\\\end{split}\]

The goal is to maximize the objective function.

Its objf is defined as:

return -(x2_ - x_ * x_ / count_);

where x2 is the second order statistics, x_ is the first order statistics, and count_ is the number of scalars.

When adding two ScalarClusterable, we use:

x_ += other->x_;
x2_ += other->x2_;
count_ += other->count_;

When subtracting one ScalarClusterable from another, we use:

x_ -= other->x_;
x2_ -= other->x2_;
count_ -= other->count_;

class kaldi_hmm_gmm.TransitionInformation(self: kaldi_hmm_gmm.lib._kaldi_hmm_gmm.TransitionInformation)

Transition-model interface used by the alignment/decoding functions.

kaldi's TransitionInformation: provides the tid->pdf map and per-transition-id queries. Implement it in Python to use decode_utterance_lattice_faster() / decode_utterance_lattice_simple() with an alternative transition model; TransitionModel implements the same interface in C++ (and is what align_utterance() requires, for AddTransitionProbs).

Note: transition_id_to_pdf_array() must return the whole map on every call (the trampoline caches it; that cached reference is what decodables keep).
